# Genetics Quest — เกมคำศัพท์พันธุศาสตร์ ม.4

เกมเว็บภาษาไทยสำหรับฝึกคำศัพท์พันธุศาสตร์ มีหน้าเริ่มเกม เลือกตัวละคร เลือกด่าน เล่นเกม ตอบคำถาม และสรุปผลรายด่าน

## ทดลองเล่นบนเครื่อง

เปิด `index.html` ในเว็บเบราว์เซอร์ หรือใช้ Live Server จากโฟลเดอร์นี้

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ โดยให้ `index.html` อยู่ที่ระดับบนสุด
3. ไปที่ **Settings → Pages** แล้วเลือก branch ที่ต้องการเผยแพร่ และโฟลเดอร์ `/ (root)`
4. เปิดลิงก์ GitHub Pages ที่ GitHub แสดงให้

ไฟล์รูปและ GIF ที่เกมเรียกใช้ต้องอยู่ในโฟลเดอร์เดียวกับไฟล์ HTML ตามที่จัดไว้ ห้ามแยกหรือเปลี่ยนชื่อ เว้นแต่จะแก้ path ในหน้าเว็บให้ตรงกัน

## รายการหน้าเว็บ

- `index.html` — หน้าแรก
- `เลือกด่านเกมคำศัพท์พันธุศาสตร์.html` — เลือกด่าน
- `เล่นเกมคำศัพท์พันธุศาสตร์.html?stage=1` — เล่นด่าน 1 (เปลี่ยนเลขเป็น 2 หรือ 3 ได้)
- `สรุปผลเกมคำศัพท์พันธุศาสตร์.html` — สรุปผลหลังจบด่าน

ข้อมูลชื่อผู้เล่น เหรียญ และผลล่าสุดเก็บใน `localStorage` ของเบราว์เซอร์ที่เล่น

## ภาพต้นฉบับ
