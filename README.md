# Genetics Quest — เกมคำศัพท์พันธุศาสตร์ ม.4

เกมเว็บภาษาไทยสำหรับฝึกคำศัพท์พันธุศาสตร์ มีหน้าเริ่มเกม เลือกตัวละคร เลือกด่าน เล่นเกมแนวนอน ตอบคำถาม สะสมเหรียญ ซื้อคำใบ้ ซื้อเกราะกันตก/หัวใจเพิ่ม และสรุปผลรายด่าน บนมือถือมีปุ่มขยายเต็มจอ

## Deploy บน Vercel หรือ GitHub Pages

1. แตกไฟล์ ZIP แล้วอัปโหลด **ไฟล์และโฟลเดอร์ทั้งหมดภายใน** ไปไว้ที่ระดับบนสุด (root) ของ repository
2. ตั้งค่าโปรเจกต์ให้ใช้ root directory เป็น `.` และไม่ต้องใส่ build command สำหรับเว็บ HTML นี้
3. Deploy แล้วเปิด URL หลัก หน้าแรกจะเริ่มที่ `index.html`

อย่าอัปโหลดเฉพาะไฟล์ HTML และอย่าเก็บโปรเจกต์ซ้อนในโฟลเดอร์ย่อย เพราะหน้าเว็บและรูปอยู่ในเส้นทางสัมพันธ์กัน

## หน้าเกม

- `index.html` — หน้าแรกและเลือกตัวละคร
- `levels.html` — เลือกด่าน
- `game.html?stage=1` — เล่นด่าน 1 (เปลี่ยนเลขเป็น 2 หรือ 3 ได้)
- `summary.html` — สรุปผลหลังจบด่าน

ไฟล์รูปและ GIF ที่เกมใช้เก็บไว้ใน `assets/` โดยใช้ชื่อไฟล์ภาษาอังกฤษเพื่อให้เส้นทางทำงานได้สม่ำเสมอบนเว็บโฮสต์

ข้อมูลชื่อผู้เล่น เหรียญ และผลล่าสุดเก็บใน `localStorage` ของเบราว์เซอร์ที่เล่น

## ภาพต้นฉบับ

โฟลเดอร์ `source-art/` เก็บภาพต้นฉบับและแอนิเมชันประกอบงาน ไม่จำเป็นต่อการเปิดเกม
